//    2  언덕 2단                           O (같은 높이끼리만)
//    ^  계단 (위/아래 높이를 자동 연결)    O
//
//  언덕 규칙
//    - 언덕 블록의 "맨 아랫줄"은 자동으로 절벽면이 된다 (이동 불가)
//      1단→지면: 1줄, 2단→지면: 2줄, 2단→1단: 1줄
//    - 높이가 다른 곳은 옆으로 오를 수 없다. 절벽면 줄에 ^ 를 넣어 계단을 만든다
//      (2줄 절벽이면 ^ 도 세로로 2개)
//
//  [objects]  오브젝트                     이동
//    .  없음          @  시작 위치
//    T  큰 나무 1     Y  큰 나무 2(침엽)    X
//    t  작은 나무 1   y  작은 나무 2(침엽)  X
//    d  고목          b  덤불               X
//    o  돌            O  바위               X
//    s  그루터기      =  쓰러진 통나무      X
//    +  묘비(십자가)                        X
//    |  갈대          "  풀 한 포기         O
//    *  꽃            p  연잎(물 위 장식)   O
